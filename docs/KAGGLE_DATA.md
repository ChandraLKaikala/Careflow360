# Kaggle Data Integration

The ZIP does **not** redistribute Kaggle datasets. This is intentional: dataset licenses differ, and the Triagegeist competition data terms prohibit redistribution outside Kaggle without permission.

## Dataset 1 — Triagegeist

Recommended source: Kaggle competition **Triagegeist**:

https://www.kaggle.com/competitions/triagegeist/data

Expected files:

```text
train.csv
chief_complaints.csv
```

Known useful fields include:

```text
patient_id
arrival_mode
arrival_hour
arrival_day
age
sex
systolic_bp
diastolic_bp
heart_rate
respiratory_rate
temperature_c
spo2
gcs_total
pain_score
num_prior_visits
triage_acuity
```

Upload to:

```text
/Volumes/<CATALOG>/careflow360_dev/landing/kaggle/triagegeist/train.csv
/Volumes/<CATALOG>/careflow360_dev/landing/kaggle/triagegeist/chief_complaints.csv
```

## Dataset 2 — Healthcare Monitoring System

Use **Patient_data-Healthcare_Monitoring_System** (synthetic IoMT data; 60,000 rows):

https://www.kaggle.com/dsv/12719441

It contains fields such as patient number, heart rate, SpO2, systolic/diastolic BP, body temperature and fall detection.

The Kaggle file is currently named `Synthetic_patient-HealthCare-Monitoring_dataset.csv`. Rename it to:

```text
healthcare_monitoring.csv
```

and upload to:

```text
/Volumes/<CATALOG>/careflow360_dev/landing/kaggle/monitoring/healthcare_monitoring.csv
```

The normalizer accepts several common column-name variants.

## Ingest

**Note:** The `02_kaggle_normalize.py` notebook has been removed as Kaggle integration is optional and not needed for core CareFlow360 functionality. The project works fully with synthetic data generated by `01_generate_sample_data.py`.

If you want to integrate Kaggle datasets, you would need to:
1. Download datasets manually from Kaggle
2. Upload to the landing volume paths above
3. Create a custom normalization script to transform them into the CareFlow360 event schemas

The notebook previously appended normalized JSON events under the same landing folders used by synthetic replay, so Bronze/Silver/Gold code does not change.

## Why not download Kaggle directly from the notebook?

Free Edition can restrict outbound network access, and embedding Kaggle credentials in notebooks is poor practice. Manual upload to a Unity Catalog volume is more reproducible and avoids leaking secrets.

## Databricks Marketplace

Marketplace can be used as an optional source if the listing and your workspace access permit it. Do not make the core project dependent on a Marketplace listing: listings, terms and workspace entitlements can change. If you use a listing, land the shared table into an adapter view/table matching the CareFlow event schemas rather than changing downstream Medallion logic.
